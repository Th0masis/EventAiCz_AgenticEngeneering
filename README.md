# Agentic Engineering

Learn how to use B&R tools for agentic engineering with any harness (GitHub Copilot, Claude Code, Codex, Cursor, …). The interactive training covers harnesses and agents, AGENTS.md, Agent Skills, plugins and the B&R marketplace, advanced workflows, and as-cli for the full plan → implement → verify → deploy → test loop.

**[📖 Open the Agentic Engineering](https://br-automation-com.github.io/agentic-bridge-training)**
